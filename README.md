# 🍔 FoodFlow

**FoodFlow** is an order management system for food establishments, designed to simplify product management and organize the workflow between employees.

## 🚀 Features

- **Product management:** Register and retrieve product information.
- **Order management:** Create and store orders in the database.
- **Order preparation:** Organize products that need to be prepared.
- **Database integration:** Store and retrieve information using MySQL.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- PDO for database connections and operations

## ⚙️ How to Run

1. Install and start [WampServer](https://www.wampserver.com/).
2. Place the project folder inside the WAMP `www` directory.
3. Create the `foodflow` database in MySQL and execute the project's SQL script.
4. Configure the database connection in `connection.php`.
5. Open the project in your browser using the appropriate local URL.

## 🎯 Purpose

FoodFlow aims to simplify order and product management, making the organization and preparation process more practical and efficient.
